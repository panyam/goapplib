# goapplib

A Go library for server-rendered web apps, with islands of client code (`@panyam/tsappkit`, `@panyam/tsappkit-solid`) and Go handlers that can run in the browser as wasm (`wasmhost`).

The docs are at **https://panyam.github.io/goapplib/**, built from `docsite/`: a getting-started guide, guides for each part with live demos, and the Go API generated from the source on `main`. SUMMARY.md is a tour of this repo.
